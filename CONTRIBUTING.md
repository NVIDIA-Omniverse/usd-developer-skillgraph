# Contributing to usd-developer-skillgraph

Contributions and PRs from the community are welcome. Rather than requiring a
formal Contributor License Agreement (CLA), we use the
[Developer Certificate of Origin](https://developercertificate.org/) to ensure
contributors have the right to submit their contributions to this project.

Please ensure that every commit carries a
[sign-off](https://git-scm.com/docs/git-commit#Documentation/git-commit.txt--s)
with an email address that matches the commit author. The sign-off certifies
that you agree to the DCO terms (reproduced in full below) for that
contribution.

Add a sign-off automatically with the `-s` (or `--signoff`) flag:

```bash
git commit -s -m "Your commit message"
```

This appends a line of the form:

```text
Signed-off-by: Your Name <your.email@example.com>
```

The email address must match the commit author. Pull requests whose commits are
not signed off cannot be merged.
